連接交易引擎

在有安裝 Freqtrade 的同一台電腦啟動此 UI。帳戶、持倉與交易紀錄會由本地引擎同步。

  1. 準備工作區尚未檢查
    npm run setup
  2. 在本機設定 Demo 金鑰尚未檢查

    此指令會開啟本機輸入流程。金鑰保留在 Windows 加密儲存，不需貼進網頁。

    powershell.exe -NoProfile -File scripts/configure-demo.ps1
  3. 啟動 Freqtrade尚未檢查
    node src/cli.mjs engine
  4. 讀取帳戶與交易尚未檢查

    按下方按鈕驗證目前所選環境。檢查只讀取資料，不會下單。

完成設定後，即可在首頁查看交易。

如何啟動研究與交易？

引擎連線後，在另一個終端執行一次現有的研究與交易週期。提案通過風控時可能送出模擬訂單。

node src/cli.mjs cycle

此頁提供查看與連線檢查；交易週期仍由 CLI 啟動。展示模式使用固定範例；Binance Demo 使用交易所虛擬資金。
